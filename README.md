# Advanced Solar Panels UNOFFICIAL PORT

Неофициальный порт **Advanced Solar Panels 4.3.0** (Icedfire, SeNtiMeL, Chocohead) на **Minecraft 1.21.1 / NeoForge 21.1.256**. Текущая версия: **0.1.8**.

Четыре солнечные панели, квантовый генератор, молекулярный преобразователь, три солнечных шлема, материалы и двойная каменная плита. Используется общая энергосеть и заряд IndustrialCraft 2 UNOFFICIAL PORT. Сохранены исходные значения генерации, уровни напряжения, рецепты, переключатели сложности и окраска гибридного и ультимативного шлемов. Есть русская и английская локализации, GUI, HUD шлемов и необязательная интеграция JEI.

## Совместимость

**Sodium и Iris не поддерживаются**: с ними возможны визуальные баги блоков, моделей, эффектов и интерфейса. Перед отправкой отчёта о такой проблеме проверьте игру без этих модов.

## Сборка

Нужны **Java 21** и JAR **IndustrialCraft 2 UNOFFICIAL PORT 0.1.24 или новее**. По умолчанию ожидается `libs/industrialcraft2-modern-0.1.24.jar`. Версию ожидаемого JAR задаёт `ic2_version` в `gradle.properties`; другой путь можно передать через `-Pic2LocalJar=libs/ic2.jar` или переменную `IC2_JAR`.

```sh
./gradlew build
```

Результат: `build/libs/advanced-solar-panels-modern-0.1.8.jar`. Все сгенерированные игровые ресурсы включены в репозиторий; для обычной сборки запуск генератора ресурсов не нужен.

JEI необязателен в игре. При сборке его API загружается из официального Maven-репозитория BlameJared; `-PwithJei=true` добавляет JEI в среду разработки. Для сборки без скачивания JEI можно указать `-PjeiLocalJar=libs/jei.jar` или переменную `JEI_JAR`. Версия Maven-зависимости задаётся свойством `jei_version`.

На Linux можно использовать `./build.sh`: скрипт сохраняет выбранный `JAVA_HOME`. На Windows используйте `gradlew.bat build` с Java 21. Локальные JAR в `libs/` не добавляются в Git.

## Проверки

Серверные проверки передачи EU, преобразования предметов, зарядки и сохранения состояния доступны через `JAVA_TOOL_OPTIONS=-Dasp.audit=server ./gradlew runServer`. Проверки сохранения энергобаланса: `JAVA_TOOL_OPTIONS=-Dasp.audit=persistence ./gradlew runServer`.

`./audit-client.sh -PwithJei=true` запускает клиентские проверки в Xvfb без звука. Нужны Xvfb, OpenAL и подготовленный тестовый мир `ASPAudit` в `run-audit/saves/`; для серверных проверок требуется принять Minecraft EULA. Скриншоты и результаты создаются в локальной папке `run-audit/`.
