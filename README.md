# Advanced Solar Panels UNOFFICIAL PORT

Порт **Advanced Solar Panels 4.3.0** (Chocohead) на **Minecraft 1.21.1 / NeoForge 21.1.256**. Текущая локальная версия: **0.1.4**.

Перенесены четыре солнечные панели, квантовый генератор, молекулярный преобразователь, три солнечных шлема, материалы и двойная каменная плита. Используется общая энергосеть и заряд IC2 UNOFFICIAL PORT. Сохранены исходные значения генерации, уровни напряжения, рецепты, переключатели сложности и окраска гибридного/ультимативного шлемов. Есть русская и английская локализации, исходные текстуры и модель преобразователя, GUI, HUD шлемов и необязательная интеграция JEI.

## Совместимость

**Sodium не поддерживается**, как и Iris, который работает поверх него. С ними возможны визуальные баги: неправильная отрисовка блоков, моделей, эффектов и интерфейса. Если что-то выглядит не так, сначала проверьте без Sodium и Iris и только потом сообщайте о баге.

## Зависимости и сборка

Нужны Java 21 и **IndustrialCraft 2 UNOFFICIAL PORT 0.1.24**. Путь к архивному JAR IC2 задаётся через `ic2_version` в `gradle.properties`; ожидается соседний проект `../industrialcraft2-modern/versions/<version>/`.

```sh
./build.sh
```

Готовый файл: `build/libs/advanced-solar-panels-modern-0.1.4.jar`.
Генератор `python tools/gen.py` обновляет ресурсы из локального образца `related/asp-reference`; готовые ресурсы уже включены в репозиторий.

## Проверки

Серверный аудит запускается в отдельном `run-server` (порт 25582, тестовый плоский мир, принятая EULA):

```sh
JAVA_TOOL_OPTIONS=-Dasp.audit=server ./gradlew runServer
```

Скрытый беззвучный клиент: `./audit-client.sh -PwithJei=true`. Для него нужен тестовый мир `run-audit/saves/ASPAudit` (копия серверного тестового мира); скриншоты сохраняются в `run-audit/audit/`. Путь к локальному JAR JEI указан в `build.gradle`; для обычного запуска JEI необязателен.

Проверки охватывают реальную передачу EU в IC2, преобразование предметов, сохранение состояния, отсутствие дублирования EU, заряд и окраску шлемов, переключение рецептов при перезагрузке ресурсов и клиентские экраны. Версия 0.1.2 исправляет связь обычной гладкой каменной плиты с её предметом при регистрации двойной плиты. 58 серверных проверок; общий сервер со всеми портами и остальным набором модов — 29, скрытый клиент с JEI — 14. Проверенный набор: IC2 0.1.23, ASP 0.1.2, EMT 0.1.9, Gravi 0.1.4, Thaumcraft 0.17.177.

Версия0.1.3 сохраняет заряд предметов даже при нулевом изменении буфера панели и принимает возврат лишнего EU из энергосети. `JAVA_TOOL_OPTIONS=-Dasp.audit=persistence ./gradlew runServer` проверяет16 настоящих сетевых сценариев, отдельные чанки источника/приёмника и полный рецепт500000EU. До исправления последний пакет терял224EU; после исправления баланс точный. Требуется IC2.24 с исправлением отметки энергии для сохранения.

Версия 0.1.4 исправляет невидимые иконки гибридного и ультимативного солнечных шлемов: обработчик цвета возвращает непрозрачный ARGB для основы и накладки. Скрытый клиентский аудит проверяет 8 вариантов настоящим GUI-рендером: пустые, заряженные и окрашенные шлемы. До исправления все 32 проверки падали и иконки давали 0 видимых пикселей; после исправления прошли 32/32, включая окраску основы и сохранение цвета накладки. Снимки до/после и журналы находятся в `versions/0.1.4/`. Человеком в игре эта версия пока не проверена.

Новый набор IC2 0.1.27 / ASP 0.1.4 вместе с полным набором модов прошёл выделенный сервер совместимости 29/29 и скрытый клиент с JEI 14/14, без ERROR/FAIL. Журналы приложены к архиву этой версии.
